Editor preferences

Advanced panel

Controls when the advanced properties panel appears while you're editing a block. This is separate from Developer Mode below.

Always show it automaticallyOpens the moment you select a block. Default.
Only show it when I open itKeeps the canvas clear — click "Advanced" on a block to open the panel.

Developer mode

Unlocks custom code, absolute positioning, and custom breakpoints in the editor. Off by default.

Independent of the Advanced panel setting above — turning this on doesn't change when the panel opens, it changes what's available inside it once open.
Companion to website-builder-ux-spec.md §3.4 and user-flows-v1.md Flow 5. Selection highlight color and the panel/canvas split are the only non-grayscale elements, kept minimal and consistent with the rest of the v0.1–v0.3 wireframe set.
One judgment call made while drawing these that wasn't explicitly settled in the spec: on a narrow editor window with nothing selected, the panel stays fully closed rather than showing Page Settings as an overlay by default — Page Settings is reached via the rail icon instead, to avoid an unrequested overlay covering the canvas on load.
